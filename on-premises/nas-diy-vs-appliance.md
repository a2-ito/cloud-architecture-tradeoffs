# 個人の NAS を自作するか既製品を買うか

個人で使う NAS を、既製品で買うか、部品を集めて自作するかを比べる。
既製品にも、メーカーの OS をそのまま使う方法と、ハードウェアだけ使って OS を入れ替える方法がある。
TrueNAS（ZFS）でのディスクの組み方（ミラー、RAID-Z1、RAID-Z2）は [個人の NAS をどの RAID で組むか](nas-raid.md) で比べた。
Synology の SHR や Unraid のアレイは、ここで違いだけに触れる。

## 1. 解きたい課題と前提

NAS は一度置くと 5 年以上使い続ける。
買うときの値段だけでなく、毎月の電気代、壊れたときの直しやすさ、OS の更新が続くかで、総額と手間が変わる。

前提は次のとおりとする。

- ディスクは 3.5 インチの同じ容量の新品を 4 本使う。ディスクの費用は、どの構成でも同じなので比べない。手持ちのディスクを使い回す場合は D で触れる。
- 置くデータは写真と動画が中心とする。あわせて Jellyfin や [テレビ録画サーバー](tv-recorder.md) などのコンテナを少し動かしたい。
- 24 時間動かす。電気代は 1 kWh あたり 31 円で計算する。1 W を 1 年動かし続けると約 8.8 kWh で、約 270 円になる。
- 置き場所は自宅の棚で、ラックやサーバー向けの騒音は受け入れない。
- 2026 年は、AI 向けの需要で DRAM の値段が大きく上がっている[^memory]。部品の値段は変わりやすいので、ここでは金額より費用の構造を比べる。

## 2. 構成

### A. 既製品をメーカーの OS で使う

```
Synology / QNAP などの 4 ベイ NAS
  └─ メーカーの OS（DSM、QTS など）
       ├─ ファイル共有、写真アプリ、バックアップ
       └─ コンテナ（Container Manager など）
```

- 箱から出してディスクを挿せば、ブラウザの画面だけで使い始められる。
- 写真の閲覧、スマートフォンからの自動アップロード、外出先からのアクセス、クラウドへのバックアップなどのアプリがそろっている。
- OS の更新、ハードウェアの故障、アプリの不具合を、1 つのメーカーにまとめて問い合わせられる。
- Synology は、2025 年のモデルで、互換性リストにない他社の HDD では新しいストレージプールを作れなくしていた。
  DSM 7.3 で方針を戻し、他社の HDD と 2.5 インチの SATA SSD でプールを作れるようになった。
  ただし、M.2 の NVMe SSD でプールやキャッシュを作るときの制限は残る[^synology-drive]。
- Synology の SHR は、中身が Linux の mdadm と LVM なので、本体が壊れても普通の Linux でディスクを読める。
- 動画をその場で変換（トランスコード）しながら配信できるかは、機種で違う。Synology の DS925+ は GPU を内蔵しない AMD の CPU を積むので向かない。Intel の CPU を積む機種なら変換できる。
- 本体の値段には、ソフトウェアとサポートの費用が含まれる。同じ性能の部品を自分で集めるより高くなりやすい。

### B. 既製品のハードウェアに別の OS を入れる

```
UGREEN NASync など、OS の入れ替えを妨げない 4 ベイ NAS
  └─ 内蔵の M.2 SSD などに TrueNAS Community Edition を入れる
       ├─ ZFS のプール
       └─ アプリ（Docker）
```

- ケース、電源、ディスクを挿す前面のベイ、静かなファンが、NAS 向けに最初から組み合わさっている。自作で一番手間のかかるケース選びと配線を省ける。
- UGREEN の DXP4800 Plus は、GPU を内蔵する Intel の Pentium Gold 8505、10GbE と 2.5GbE を積む。動画の変換もできる。
- 標準のメモリは 8 GB なので、アプリを動かすなら増設が要る。汎用の SO-DIMM を挿せるが、スロットの数とケースに入る部品の範囲に限られる。
- メーカーは別の OS を入れた状態をサポートしない。BIOS で watchdog を切らないと、再起動を繰り返す。前面の LED などは、メーカーの OS でないと制御できないことがある。
- UGREEN は、別の OS を入れてもハードウェアの保証は変わらないとしている[^ugreen]。
- 写真の自動アップロードや外出先からのアクセスは、Immich や Tailscale などのアプリを自分で入れて用意する。C と D も同じ。

### C. 自作して TrueNAS Community Edition を入れる

```
自作の PC（4 ベイ以上のケース、省電力の CPU、SATA ポート）
  └─ TrueNAS Community Edition（無料）
       ├─ ZFS のプール
       └─ アプリ（Docker）、仮想マシン
```

- ケース、マザーボード、CPU、メモリ、電源を自分で選ぶ。ベイの数、メモリの量、10GbE の有無、GPU を内蔵する CPU にするかを、使い方に合わせて決められる。
- 部品はどれも汎用品なので、壊れた部品だけを買い直せる。メーカーがサポートを終えても、OS を入れ直して使い続けられる。
- TrueNAS Community Edition は無料である。25.10（Goldeye）では、通常 6〜8 週間おきにセキュリティ修正が出ている。次のメジャーバージョンの TrueNAS 27 は 2026 年 12 月に出る予定で、ここから年 1 回のリリースになる[^truenas]。
- ZFS はメモリをキャッシュに使う。家庭で使う 4 本の構成なら 8 GB から動くが、アプリを動かすなら 16 GB 以上がほしい。2026 年はメモリの値段が上がっていて、自作の費用を押し上げる。
- ECC メモリは、メモリの化けたデータをディスクに書かないために有効だが、必須ではない。対応する CPU とマザーボードが限られ、費用が上がる。
- 待機中の消費電力は、選んだ部品で大きく変わる。デスクトップ向けの CPU と大きめの電源を選ぶと、既製品より 10 W 以上多くなることがあり、年に 3,000 円前後以上の差になる。
- 騒音もケースとファンの選び方で決まる。
- 部品の相性、BIOS の設定、ケースの冷却を、自分で調べて解決する必要がある。

### D. 自作して Unraid を入れる

```
自作の PC
  └─ Unraid（有料）
       ├─ アレイ（パリティ 1〜2 本 + 容量の違うデータディスク）
       ├─ キャッシュやアプリ用の SSD のプール
       └─ アプリ（Docker）、仮想マシン
```

- Unraid のアレイは、ファイルを 1 本のディスクにまとめて書き、別のディスクにパリティを置く。容量の違うディスクを混ぜられ、1 本ずつ足せる。手持ちのディスクを使い回せるので、ディスクの費用を抑えられる。
- データディスクは 1 本ずつ普通のファイルシステム（XFS、Btrfs、ZFS）なので、ほかの Linux に挿しても単体で読める。
- 読み書きしないディスクは止めておけるので、写真や動画のように普段は触らないデータが多いと、待機中の消費電力を下げやすい。
- 読み込みはディスク 1 本分の速さにとどまる。書き込みはパリティの計算でさらに遅いので、普通は SSD のプールを前に置いて受け止める。
- 有料で、Starter（49 USD）、Unleashed（109 USD）、Lifetime（249 USD）がある。Starter は、キャッシュの SSD も含めてつなげる機器が 6 台までである。HDD 4 本に NVMe を 2 本足すと上限に届く[^unraid]。
- Starter と Unleashed は 1 年間の更新が付き、その後の更新は年 36 USD かかる。払わない場合は、今のマイナーバージョンのパッチだけを受け取れる。そのマイナーバージョンのサポートが終わると、セキュリティ修正も止まる。

### E. 採らない構成

- 中古のサーバーやワークステーション: 安く手に入り、ECC メモリも使えるが、待機中の消費電力と騒音が大きい。自宅の棚に置く前提に合わない。
- 古いデスクトップ PC の流用: 部品代はかからないが、ベイが足りず、ディスクを交換するたびにケースを開ける。消費電力も読みにくい。

## 3. トレードオフ

| 観点                       | A. 既製品 + メーカーの OS        | B. 既製品 + TrueNAS                 | C. 自作 + TrueNAS               | D. 自作 + Unraid                           |
| -------------------------- | -------------------------------- | ----------------------------------- | ------------------------------- | ------------------------------------------ |
| 初期費用（ディスク除く）   | 高い（ソフトとサポート込み）     | 中くらい。メモリの増設が要る        | 部品次第。2026 年はメモリが高い | C + ライセンス代。手持ちのディスクを使える |
| 待機中の消費電力           | 低い。メーカーが調整済み         | 低い                                | 部品次第。選び方を誤ると高い    | ディスクを止められるので低い               |
| 騒音                       | 静か                             | 静か                                | ケースとファン次第              | C と同じ                                   |
| 組み立てと初期設定         | ほぼ不要                         | OS を入れ、watchdog を切る          | 部品選び、組み立て、BIOS 設定   | C と同じ                                   |
| 写真の自動アップロードなど | メーカーのアプリがある           | Immich などを自分で入れる           | B と同じ                        | B と同じ                                   |
| ハードウェアでの動画の変換 | 機種次第（DS925+ は不可）        | 可                                  | CPU 次第                        | CPU 次第                                   |
| 拡張性                     | 本体の範囲内                     | 本体の範囲内                        | 高い（ベイ、メモリ、NIC）       | 高い。容量の違うディスクも可               |
| 故障したときの直し方       | メーカー修理。本体ごと交換もある | 本体はメーカー修理、OS は自分       | 壊れた部品だけ買い直す          | C と同じ                                   |
| OS の更新と寿命            | メーカーのサポート期間に縛られる | TrueNAS の更新が続く限り使える      | B と同じ                        | 有料の更新か、セキュリティ修正の止まった版 |
| 問い合わせ先               | メーカー 1 か所                  | ハードはメーカー、OS はコミュニティ | コミュニティだけ                | Unraid 社とコミュニティ                    |
| ロックイン                 | 強い（アプリ、ディスクの方針）   | 弱い（ZFS なので別の機械に移せる）  | 弱い                            | 弱い（ディスクは 1 本ずつ Linux で読める） |

ZFS のプールは、別の機械に TrueNAS を入れてディスクを挿し替えれば読める。
B と C のあいだは、ディスクを移すだけで行き来できる。
A のロックインの本体は、SHR ではなく写真アプリなどの独自機能とディスクの方針にある。
独自機能に頼るほど、別の構成に移るときにデータの移し替えと使い方の作り直しが要る。

## 4. 選ぶ基準

- NAS の面倒を見る時間をかけたくないなら、**A. 既製品 + メーカーの OS** を選ぶ。写真のアップロードや外出先からのアクセスまで、メーカーのアプリで済む。ただし、ディスクの互換性の方針、OS のサポート期間、動画の変換が要るなら CPU を、買う前に確かめる。
- ZFS と TrueNAS を使いたいが、組み立てはしたくないなら、**B. 既製品 + TrueNAS** を選ぶ。ケースと電源の手間を省きつつ、メーカーの OS に縛られない。メーカーのサポートを受けられないことと、写真のアプリなどを自分で用意することは受け入れる。
- ベイやメモリを増やしたい、仮想マシンも動かしたい、部品を交換しながら長く使いたいなら、**C. 自作 + TrueNAS** を選ぶ。待機中の消費電力と騒音が小さくなる部品を選ぶことが前提になる。
- 手持ちの容量の違うディスクを使い回したい、普段はディスクを止めて電気代を抑えたいなら、**D. 自作 + Unraid** を選ぶ。読み書きの速さより、柔軟さと省電力を優先する場合に向く。更新料を払い続けるか、Lifetime を買う前提で考える。
- どれを選んでも、RAID はバックアップの代わりにならない。NAS の外にバックアップを置く方法は [個人の NAS をどの RAID で組むか](nas-raid.md) を参照。
